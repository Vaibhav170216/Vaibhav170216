## 📊 Featured Projects

###  [GeoAI Research Assistant](https://github.com/Vaibhav170216/geoai-research-assistant)
End-to-end RAG system for exploring GeoAI, Earth Observation and Remote Sensing research papers. Hybrid retrieval (SQLite FTS + semantic search fused via RRF), Streamlit UI, a full RAGAS evaluation pipeline and monitoring with Grafana.

**Tech:** `RAG` `Hybrid Search` `LangChain` `Streamlit` `RAGAS` `Grafana`

###  [Deep Learning for Earth Observation](https://github.com/Vaibhav170216/Masters-Thesis-GeoAI-1D-CNN)
Compared multiple CNN architectures for Sentinel-2 Land Use/Land Cover classification, achieving a 90% F1-score using a ResNeXt-based 1D CNN and presenting the work at ICGCE 2024.

**Tech:** `Deep Learning` `Geospatial Analysis` `Remote Sensing` `1D CNN`

###  [Transformers & Vision Transformers from Scratch](https://github.com/Vaibhav170216/transformers-and-vit-from-scratch)
Built transformer and Vision Transformer (ViT) architectures from scratch in PyTorch. Deep dive into attention mechanisms, positional encodings and patch embeddings.

**Tech:** `PyTorch` `Transformers` `Vision Transformer (ViT)` `NLP`

###  [LLM Fine-tuning with LoRA](https://github.com/Vaibhav170216/Finetuning-Llama-3-on-Dolly-Dataset-with-LoRA)
Fine-tuning Llama 3 on the Dolly dataset using Low-Rank Adaptation (LoRA) for parameter-efficient training. Exploring efficient fine-tuning techniques for large language models.

**Tech:** `Llama 3` `Weights and Biases` `LoRA`
